# Create a New Skill

## Usage
`/create-skill <skill_name> [category] [tier]`

## Description
Creates a new skill using the enhanced SDK and compound integration methodology. Supports individual skill creation with zero hallucination standards and progressive documentation.

## Arguments

- `skill_name`: Name of the skill to create (required)
- `category`: Skill category (optional, default: "general")
  - Options: `core_technology`, `domain_expertise`, `integration`, `meta_skills`, `quality_assurance`, `resource_optimization`, `validation`, `jit_compiler`, `scheduler`, `signature_framework`
- `tier`: Skill complexity tier (optional, default: "intermediate")
  - Options: `basic`, `intermediate`, `advanced`, `expert`

## Process

1. **Skill Discovery**: Analyze requirements and match to existing patterns
2. **Template Selection**: Choose appropriate skill template based on category
3. **Implementation**: Generate skill with zero hallucination validation
4. **Documentation**: Create progressive disclosure documentation
5. **Testing**: Implement comprehensive test suite
6. **Integration**: Add to skill registry with proper categorization
