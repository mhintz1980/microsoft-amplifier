## 🎯 OPTIMIZATION PRINCIPLES

### 1. Role Definition
**Instead of**: "You are a [role] with deep knowledge of..."
**Use**: "ROLE: [role]"

### 2. Domain Specification
**Instead of**: "with knowledge of A, B, C, D, E..."
**Use**: "DOMAIN: A, B, C"

### 3. Focus Statement
**Instead of**: "You provide guidance on..."
**Use**: "FOCUS: [specific objective]"

### 4. Structured Process
**Instead of**: No process mentioned
**Use**: "PROCESS: Step1 → Step2 → Step3"

### 5. Output Format
**Instead of**: No output specification
**Use**: "OUTPUT: [specific format]"

## 🚀 HOW TO OPTIMIZE YOUR PROMPTS

### Step 1: Identify Core Elements
Extract the essential information:
- **Role**: What expertise is needed?
- **Domain**: What knowledge areas?
- **Focus**: What's the main objective?

### Step 2: Use Structured Format
Apply this template:
```
=== [ROLE] ===

ROLE: [Concise role description]
DOMAIN: [Key knowledge areas]
FOCUS: [Primary objective]

PROCESS: [Brief steps]
OUTPUT: [Desired format]
```

### Step 3: Eliminate Redundancy
Remove these common wastes:
- "You are" → Start directly with role
- "with deep knowledge of" → "DOMAIN:"
- "You provide comprehensive guidance" → "FOCUS:"
- Redundant adjectives: "comprehensive, practical" → remove

### Step 4: Add Structure
Include these elements if missing:
- **Process**: How should the AI think?
- **Output**: What format should it use?
- **Constraints**: Any boundaries or limits?
